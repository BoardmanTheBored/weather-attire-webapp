## Working folders

- `art/work/` — raw generations and in-progress files. Not committed (see `.gitignore`).
- `assets/art/` — final transparent PNGs the app uses (committed). Same folder layout as `assets/placeholders/`.
- `scripts/art_tools.py` — helper for background removal, overlay extraction, and alignment previews (`pip install pillow`).

## Canvas

Every character layer shares one canvas so overlays line up. **Decided at the pilot (2026-10-16): 384×768, ratio 1:2**, which is what the app already uses, so no CSS or placeholder change is needed. Gemini returned a 1408×768 landscape image with the figure centered, so every raw image is cropped with the same box: `--box 512 0 896 768` (the figure sits at x 572–834, leaving about 56 px of margin each side for jackets and hats). If a later generation frames the figure differently, check that its figure box still matches before cropping. Never resize or crop one layer on its own.

## Style prompt (use at the start of every prompt)

> Flat illustration in a rustic, vintage American WPA poster style: bold dark outlines, a limited muted palette (faded red, mustard, navy, olive, cream), subtle paper-print texture, no gradients, no shadows, no text.

Edit this once and keep it identical for all 23 assets; consistency matters more than any single image.

## Pilot (A1, before generating everything)

Goal: prove that an item generated by editing the mannequin can be extracted and lines up in the app.

1. **Mannequin.** New Gemini chat. Prompt: *"[style prompt] A plain featureless wooden artist's mannequin, full body, front view, standing straight, arms slightly away from the body, feet shoulder-width apart, centered with space around the whole figure. Solid flat magenta (#FF00FF) background. No clothing, no ground, no shadow."* Aspect ratio: the tallest available. Save as `art/work/mannequin_raw.png`.
2. **One shirt.** Same chat, or a new chat with `mannequin_raw.png` attached. Prompt: *"Using this exact image, add a short-sleeved crew-neck t-shirt in faded blue. Do not change the pose, the size or position of the figure, the background, or the art style. Keep the exact same framing."* Save as `art/work/shirt-1_raw.png`.
3. **Crop, make the transparent mannequin, and extract the shirt layer.** Raw files may be JPG; that is fine. Measure the background color first (it is rarely exactly `FF00FF`; the pilot's was `CF4CB0`) and pass it as `--color` / `--bg`.
   ```
   python scripts/art_tools.py crop art/work/mannequin_raw.jpg art/work/mannequin_crop.png --box 512 0 896 768
   python scripts/art_tools.py crop art/work/shirt-1_raw.jpg art/work/shirt-1_crop.png --box 512 0 896 768
   python scripts/art_tools.py keyout art/work/mannequin_crop.png assets/art/character/mannequin.png --color CF4CB0 --defringe
   python scripts/art_tools.py overlay art/work/mannequin_crop.png art/work/shirt-1_crop.png assets/art/outfit/shirt-1.png --bg CF4CB0
   python scripts/art_tools.py preview art/work/pilot.png assets/art/character/mannequin.png assets/art/outfit/shirt-1.png
   ```
   `--bg-distance` (default 110) drops pixels close to the background color. Do not raise it much: a garment whose color is near the background (a faded blue shirt on pink) gets eaten. Pick garment prompts and a background color that are far apart.
4. **Judge it.** Open `art/work/pilot.png`. The shirt should sit on the torso with clean edges and no halo. The script prints where the change is: a shirt should cover roughly the shoulders to the hips and not reach the head or feet. If it does, Gemini moved or resized the figure; regenerate. If the cut is ragged, adjust `--threshold` (lower catches more, higher drops noise) or `--grow 1`.
5. **Decide.** If the shirt lines up, continue with all 23. If not after a few tries, tell the Agent: the fallback is FLUX.1 [schnell] on this machine's RTX 4060 (Apache 2.0), with its own consistency limits.

## Prompt templates for the rest (after the pilot passes)

Always attach `mannequin_raw.png` and repeat the "do not change" sentence.

| Asset | Prompt after "Using this exact image, add…" |
|---|---|
| Shirt ×3 | a short-sleeved crew-neck t-shirt in faded red / faded blue / olive green |
| Pants ×3 | straight-leg trousers in navy / tan / grey (shirt not required) |
| Shoes ×3 | sneakers / loafers / canvas shoes, on the feet only |
| Jacket, light | an open, unzipped lightweight jacket with long sleeves |
| Jacket, heavy | a thick puffy winter coat, zipped, with long sleeves |
| Hat, sun | a wide-brimmed straw sun hat |
| Hat, rain | a bright yellow rain hood pulled up over the head |
| Hat, beanie | a knitted beanie with a pom-pom |

Each item is extracted against the **bare** mannequin, so layers do not depend on each other. Shirt and pants colors are named in `js/assets.js` (red, blue, green; navy, tan, grey) and shoe names (sneakers, loafers, canvas shoes) — change those lists if the generated colors differ.

## Icons (A3, 64×64)

Generate on a solid magenta background, one prompt per icon, with the same style prompt and a thick dark outline so each reads in greyscale: thermometer, clear/sunny, overcast, rain, snow, windy, umbrella, hydration drop. Remove the background with `keyout`, then crop and resize each to a square PNG. Reminder and condition icons must make sense without color (R13).

## Pilot result (2026-10-16)

Tool output on the Developer's two Gemini generations (mannequin, then the same mannequin with a blue shirt):
- The figure's bounding box was identical in both raw images (x 572–834, y 46–722), so Gemini did not move or resize it.
- The extracted shirt covers y 0.22–0.56 and x 0.20–0.80 of the canvas (shoulders to hips, sleeves to the arms), nothing near the head or feet.
- The keyed-out mannequin is fully opaque across the body and transparent outside; the composite shows the shirt aligned with clean edges and about 18 stray pink pixels in a 295,000-pixel layer.
